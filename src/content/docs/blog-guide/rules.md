# 文章规范

文章就是 `_posts/` 下的 Markdown 文件，两个硬规矩：

1. 文件名必须 `YYYY-MM-DD-名称.md`
2. 开头一段用 `---` 包起来的 front matter

这两条错一条，文章就不会出现在站点上，而且**不会有任何报错**。
