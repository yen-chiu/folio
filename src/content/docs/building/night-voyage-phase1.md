# Vesper · 夜航计划 / Night Voyage

> 让网站记得时间，也记得读者。

- **版本**：v1.0（2026-11-21）
- **项目**：[Vesper 主站](https://yenchiu.com/) / [源码仓库](https://github.com/yen-chiu/yen-chiu.github.io)
- **状态**：设计定稿，待开发；不代表功能已上线
- **范围**：第一期三项独立功能，轻量静态站点增强
- **开发约束**：独立开发、验证、PR 审核；实施阶段未经另行批准不合并或部署

## 一、目标与已确认决策

在不妨碍阅读、不采集个人阅读历史的前提下，为 Vesper 增加：

1. **阅读书签 / Reading Bookmark**：文章阅读位置仅保存在浏览器本地；再次打开时由访客主动选择「继续阅读」或「从头开始」，**不得自动跳转**。
2. **旧文来信 / Letters from the Past**：**仅在首页**展示真实公开旧文，按往年今日、附近日期、旧文漫游依次推荐。
3. **月相日历 / Lunar Almanac**：**全站页脚小图标**，点击才展开日期、月相、建站天数及时间档案入口。

不建设独立夜航页面、账号系统、云同步、AI 摘要、天气 API、背景音乐、复杂动画或 Folio 阅读进度同步。

原则：安静优先、真实性优先、本地优先、渐进增强、低耦合、旧浏览器兼容。三个模块共用设计规范，但不强行共享业务状态。

## 二、阅读书签：交互与数据

### 交互

- 首次阅读正文超过约 **10%** 才开始记录；滚动时节流写入（建议 800–1500ms），页面隐藏时尝试保存。
- 再次进入有有效未完成记录的文章，在标题下方显示**非模态**提示：「上次读到了这里。继续阅读 / 从头开始」。
- 「继续阅读」优先恢复到章节锚点及章节内位置；失效时回退到正文整体比例；无法安全定位则停留开头并告知用户。
- 「从头开始」关闭提示，不执行自动滚动；随后正常更新新进度。
- 正文末尾约 95% 且确实到达正文结束位置时标记已读完，不把评论和页脚计入正文；完成后不再提示。
- 提供清除当前文章及全部阅读记录的能力。禁用存储时正常阅读，不能谎称保存成功。

### Schema

```ts
interface ReadingBookmark {
  version: 1;
  articleId: string;            // 稳定内容 ID，不能仅使用标题
  pathname: string;             // 规范化 URL
  headingId: string | null;     // 有效章节锚点
  progress: number;             // 正文比例 [0,1]
  scrollRatio: number;          // 正文内相对位置 [0,1]
  contentFingerprint: string | null;
  savedAt: string;              // ISO timestamp
  completed: boolean;
}
interface ReadingBookmarkStore {
  schemaVersion: 1;
  items: Record<string, ReadingBookmark>;
}
```

- 存储键：`vesper:night-voyage:bookmarks:v1`；`localStorage`，最多保留最近 50 篇，超额按 `savedAt` 淘汰。
- 读取时校验 JSON、字段和数值范围；损坏记录安全忽略；多标签页处理 `storage` 更新冲突。
- 文章结构变化：锚点 → 正文比例 → 放弃定位；不依赖绝对 `scrollY`。图片、字体与 Astro 客户端导航的布局稳定性必须验证。
- 不与评论身份、GitHub 登录、访问分析或第三方追踪关联；不上传阅读记录。

## 三、旧文来信：真实内容与推荐

### 首页卡片

展示「LETTERS FROM THE PAST」、匹配说明、真实文章标题、发布日期、现有 `description`（如有）、原文链接、所属生长年度，以及候选至少两篇时的「再换一封」。无符合条件的文章则不渲染卡片，不显示虚构占位内容。不得自动轮播。

### 候选与优先级

只从现有 Astro `blog` collection 读取已公开且 `draft === false`、日期有效、至少发表一年的文章；排除未来日期、重复文章及无效链接。按以下顺序：

1. **往年今日**：同月同日且已满一年。
2. **往年这一周**：历史年份同月同日前后 ±7 天，按日期距离排序。
3. **旧文漫游**：其他已满一年的公开文章。
4. **无候选**：隐藏卡片。

同一天默认选择应由日期与文章稳定 ID 决定，刷新不随机变化；只有访客点击「再换一封」才切换。2 月 29 日使用明确的公历匹配规则，不默认为 2 月 28 日。摘要仅使用真实文章元数据，不编造作者引语。发布日期以文章元数据为准，不冒充独立考证的首次公开日期。

### Schema

```ts
type PastLetterMatch = 'on-this-day' | 'nearby' | 'discovery';
interface PastLetter {
  articleId: string;
  title: string;
  url: string;
  publishedAt: string;
  excerpt: string | null;
  anniversaryYear: number;
  matchType: PastLetterMatch;
}
interface PastLetterCandidate {
  id: string;
  title: string;
  url: string;
  publishedAt: string;
  excerpt: string | null;
  tags: string[];
}
```

候选索引建议在 Astro 构建期从公开内容生成；客户端仅按日期选择，不重复解析 Markdown。链接使用现有 `getPostPath` 和站点 URL 工具。

与「岁月标本馆」共用建站周年规则：2023-03-12 起，`Asia/Shanghai`，左闭右开；例如 2024-03-12 至 2025-03-12 属标本 002（`/herbarium/2024`）。标本馆尚未上线时隐藏年度链接，不指向未发布页面。**本期不在标本馆或关于页重复渲染旧文卡片。**

## 四、月相日历：页脚交互与计算

### 交互

页脚默认仅显示小月相图标和简短名称/日期；访客点击后展开轻量详情，包含站点日期、月相名称、**约**月龄、**约**照明比例、建站天数及「一树春秋」「岁月标本馆」入口（目标未上线时隐藏）。不自动弹窗，不持续旋转。

面板支持关闭按钮、Escape、键盘导航、焦点管理、移动端安全区域及 `prefers-reduced-motion`。

### Schema

```ts
interface MoonSnapshot {
  calculatedAt: string;   // UTC ISO timestamp
  phaseFraction: number;  // [0,1]
  illumination: number;   // [0,1] approximate
  ageDays: number;
  phaseName: string;
  method: string;         // 算法名称与版本
  approximate: boolean;
}
```

- 天文计算基于 UTC 时间戳；日期展示及建站天数使用 `Asia/Shanghai`。
- 建站日为 **2023-03-12**，建站当天定义为第 1 天。
- 使用可测试的轻量月相算法；不能简单以农历日数除以 30，也不能把农历十五等同于精确满月时刻。
- 必须注明算法、近似性质、误差和适用范围；与可信天文历表核对朔、上弦、望、下弦等典型时刻。
- 首次展开时计算，标签页重新可见及跨站点日期时更新；不使用高频定时器、地理位置或天气服务。

## 五、现有源码整合

已核对的主站入口与建议：

**建议新增目录**（开发前以实际仓库为准）：


- 书签只在文章页面绑定正文监听；旧文索引仅发送给首页；月相可全站存在但默认轻量。

- Astro 客户端路由需覆盖首次加载、前进后退、重复进入、监听清理、页脚重复初始化及滚动恢复冲突。
- 标本馆与头像动画尚有独立 PR，夜航计划不得混合提交或复制另一套周年口径。
- 开发阶段建议独立分支 `feat/vesper-night-voyage`；本次**仅归档文档，不修改主站功能源码**。

## 六、视觉、无障碍与性能

- 关键词：暮蓝、月光、旧纸、微光、留白、克制。继承 Vesper 主题变量，支持深浅色。
- 建议动效：书签提示 150–200ms；旧文切换 150–250ms；月相面板 180–240ms；按钮反馈 100–150ms。减少动画设置下禁用非必要动画。
- 语义化按钮、可见焦点、足够对比度；不能只靠颜色表达状态；小屏无横向溢出。
- 不新增追踪或不必要网络请求；不持续高频计算月相；滚动存储节流；不显著增加 CLS。
- 保持 Chrome 99、当前 Chromium、Firefox、Safari、Android Chrome 与 iOS Safari 的基本功能。

## 九、验收标准

- [ ] 书签只在用户主动点击时恢复，正文可正常阅读，存储不可用时安全降级。
- [ ] 书签能合理定位，已读完不反复提示，提供记录清理。
- [ ] 旧文来信**仅首页**展示；真实公开文章、稳定日期选择、有效链接、无候选时隐藏。
- [ ] 月相**仅页脚小入口**默认展示；点击展开，算法和近似性可核验。
- [ ] 时间口径与一树春秋/岁月标本馆一致；未上线入口不暴露坏链接。
- [ ] Astro 构建、类型检查、测试、兼容性和回归通过。
- [ ] 无新的第三方追踪，不上传阅读记录；无明显布局跳动或大型依赖。
- [ ] 交付可审核 PR、变更清单、测试报告、算法来源、已知问题。

## 十、风险与边界

- 文章结构变动导致定位错误 → 锚点与比例回退，不强行使用像素位置。
- 浏览器隐私模式或配额限制 → 本地存储安全降级。
- Astro 路由与滚动恢复冲突 → 监听清理和集成测试。
- 旧文不足或日期不可信 → 不展示、不编造。
- 标本馆尚未合并 → 暂隐藏年度链接，后续复用统一工具。
- 月相近似算法误差 → 明示近似与对照来源。
- 多个开发 PR 并行 → 独立提交、审查依赖与冲突。
