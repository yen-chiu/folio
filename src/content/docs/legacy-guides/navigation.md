<h1 id="navigation">Navigation</h1>

<p>默认页面布局支持各种导航功能:</p>

<ul>
  <li><strong>主导航（main navigation）</strong> 面板，突出显示当前选定的页面；</li>
  <li>一个 <strong>辅助（auxiliary）</strong> 链接列表，显示在所有页面上；</li>
  <li><strong>breadcrumbs</strong>列表,显示在除顶级页面之外的所有页面上；</li>
  <li>指向<strong>子页面（child pages）</strong>（所谓的“目录”）的可选链接列表；以及</li>
  <li>用于<strong>页内导航（in-page navigation）</strong>的部分标题链接，带有可选的<strong>返回顶部（back-to-top）</strong>链接。</li>
</ul>

<p>请参阅以下页面以了解如何指定这些功能以及说明性示例。</p>
