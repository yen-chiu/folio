Folio 把使用说明、实践记录和参考资料放在同一个地方。先按你要做的事情选择入口。

## 我想写文章或维护博客

从[博客指南](/folio/blog-guide/)开始。里面按登录、写作、图片和发布流程组织，也有 Front Matter 和评论说明。

## 我想查建站过程和解决办法

查看[建站笔记](/folio/building/)。这里记录实际做过的改动、遇到的问题、验证结果与尚待完成的目标。

## 我想找工具或零散资料

打开[资料导航](/folio/resources/)或[其他笔记](/folio/notes/)。

## 搜索与阅读

- 顶部搜索支持中文关键词；桌面可以使用 Ctrl + K，macOS 使用 Command + K。
- 手机点开菜单查看目录；长文可通过「本页内容」跳到具体章节。
- 亮色、暗色或跟随系统可在主题选项里切换。

## 关于旧主题参考

侧边栏的「旧主题参考」保留了原文档库里的 Jekyll / Just the Docs 教程和演示。这些内容属于历史参考，不能直接当作 Folio 的配置方法。
